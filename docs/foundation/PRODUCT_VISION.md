BeManager será un manager profundo de baloncesto para navegador, inicialmente
orientado a escritorio y con diseño adaptable a móvil.

## Principios confirmados

- El universo deportivo será **ficticio**: no se utilizarán equipos,
  jugadores, escudos, logotipos ni marcas oficiales reales.
- El mundo estará inspirado en la estructura, cultura, nivel competitivo y
  diversidad del baloncesto real, sin crear simples copias renombradas
  uno a uno.
- El desarrollo empezará por el ecosistema europeo de clubes profesionales.
- El núcleo del juego no debe quedar limitado a Europa ni contener
  supuestos europeos incrustados.
- El corazón diferencial del juego es la interacción creíble entre
  **motor de partido, tácticas y atributos**, diseñados y construidos como
  un único núcleo de juego (ver `MATCH_CORE_PRINCIPLES.md`).
- Antes de construir temporadas o gestión de carrera se creará un
  Laboratorio de Partido que use exactamente el mismo motor del juego real.
- La simulación deberá ser reproducible mediante semillas y observable
  mediante diagnósticos internos durante el desarrollo.
- El proyecto crece mediante módulos y datos versionados; ampliar países o
  ecosistemas no debe implicar reescribir el núcleo.

Estos principios son duraderos. Un cambio en alguno de ellos requiere una
decisión explícita de Dennis, no una interpretación de Claude Code.
